Energy Efficiency Campaign Sentiment Analysis

📌 Project Overview

This project presents an analytical study evaluating public sentiment and audience engagement regarding the Saudi National Energy Efficiency Awareness Campaign (featuring key hashtags like #وفرت_وأنورت, #لتبقى, and #المجد_للوطن) on Twitter (X).

📊 Key Findings & Metrics

Total Analyzed Tweets: 21,000+ Tweets

Sentiment Breakdown:

🟢 Positive: 48.3% (10.13K) — High positive reception, praising the creative direction and campaign messaging.

🟡 Neutral: 31.3% (6.58K) — Informational retweets and awareness sharing without explicit opinions.

🔴 Negative: 20.4% (4.28K) — Constructive feedback, suggestions, or technical observations regarding the campaign.

Top Campaign Hashtags:

#وفرت_وأنورت (5,664 occurrences)

#لتبقى (2,071 occurrences)

#المجد_للوطن (1,544 occurrences)

🛠️ Tech Stack & Skills

Data Preprocessing & NLP: Python (Text normalization, cleaning Arabic noise, and duplicate removal).

Data Visualization: Interactive Dashboard design to showcase key metrics and actionable insights.
